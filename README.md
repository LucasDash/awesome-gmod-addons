# My awesome Garry's Mod addons

This is the public repository for the Lua files that make up most of my addons, available on the Steam Workshop for Garry's Mod.
Among them, the two main ones are:
- [Contact IK](https://steamcommunity.com/sharedfiles/filedetails/?id=3818897507)
- [Dash Reality](https://steamcommunity.com/sharedfiles/filedetails/?id=3829248229)

[Agent Session Profiles](agent_session_profiles/README.md) is an optional, inert-by-default development-session addon. It is an experimental source candidate, not a Workshop release.
